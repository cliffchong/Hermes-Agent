## 技術實作
- **版面**：固定 1920×1080 canvas，`transform: translate(-50%,-50%) scale(min(vw/1920, vh/1080))`，在任何視窗尺寸都保持 16:9 並置中。
- **設計 token**：CSS 變數；淺色（暖白 #fbfaf7／墨綠灰文字）＋深色（#111820）；單一強調色 teal，無漸變、無玻璃擬態濫用。
- **字體**：Noto Sans TC → PingFang TC → Microsoft JhengHei 系統鏈（無外部字體請求）。
- **互動**：上／下一頁按鈕、頁碼、頂部進度條、主題循環（跟隨系統／淺／深）、列印、全屏；鍵盤 ← → ↑ ↓ Space Enter Backspace PageUp PageDown Home End、`F` 全屏、`P` 列印、`T` 主題；手機支援左右滑動。
- **狀態**：目前頁與主題寫入 `localStorage['helen.meeting-deck.v1']`，並與 URL hash（`#12`）雙向同步，可直接分享某一頁。
- **列印**：`@page { size: 1920px 1080px; margin: 0 }`，列印時強制淺色 token、隱藏 HUD／控制列／鍵盤提示、每頁一張 slide（`page-break-after: always`），全部顏色用 `print-color-adjust: exact` 保留。

## 修過的問題（值得記低）
1. **canvas 置中失效**：原本 `.stage { display:grid; place-items:center }` 對超寬（1920px）子元素會靠左溢出，導致畫面被切。改用絕對定位 `left/top: 50%` ＋ `translate(-50%,-50%) scale(s)` 才可靠置中。
2. **列印時頁碼全疊在一起**：`.slide` 在列印設 `position: static`，令 `position:absolute` 的頁碼改以頁面為基準，20 頁頁碼全部堆在第一頁。列印改 `position: relative` 後每頁各自定位。
3. **列印不應出現鍵盤提示**：`@media print` 隱藏 `.hint`。
4. **控制列壓住內容**：控制列降至 opacity .5（hover／focus 回復 1），頁碼移到左下角避開。

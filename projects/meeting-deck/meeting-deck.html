教學原則：少理論，多 demo

May · 課堂結構

  • 3 小時唔好塞太多 module
  • 學員若已上過 MS-4018 / MS-4004，可以少啲「Copilot 是乜」的 introduction，時間留多啲做 hands-on

Johnny · 教學風格

  • 少理論、多 demo，多用學員的真實文件做案例
  • 保持「由 0 到 1 + 由文件到 slide」的 workflow，唔好只停留在 chat box 層面

參考經驗Johnny 分享

之前做 PPT + AI 課，最後 2 小時用 Copilot／Gemini／Kimi 幫學生把 internal memo 變成 slide，效果幾好——學生感覺「即學即用」。希望 Copilot 課與 Generative AI workshop 都保持這種體驗。

證據 · 課程設計

3 小時課程：1 + 1 + 1

May 的建議——三小時分三節，最後一節把 governance 收進去。

第 1 小時
Copilot Chat 概念 + prompt framework
第 2 小時
365 apps demo：Word / Excel / PowerPoint / Outlook
第 3 小時
Case study + group exercise（包含 governance）

彈性：若學員已上過 MS-4018 / MS-4004，可壓縮 introduction 部分，把時間留給 hands-on。

證據 · 課程設計

6 小時主幹：3 個 module × 2 小時

Module 1 · 2 小時
Copilot Chat理解定位、prompt 基礎、Chat + web context
Module 2 · 2 小時
365 Copilot featuresWord / Excel / PowerPoint / Outlook demo + hands-on
Module 3 · 2 小時
Use cases + create agentCase study、Copilot Chat agent、governance

提醒（Ken）：這個 split 清晰，但 6 小時對管理層可能太長，客戶可能先試 3 小時 version，再考慮 extension。
